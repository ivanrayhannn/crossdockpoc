From the staging tables to the upload files

Each scenario starts from the same state (period 202612 already sent to AP POLE and GTOPAS), changes the master, then D/S clicks [Sync] at 10-Dec 11:00. SP_STG_SYNC sets the rows to SYNC_STATUS 1 with SYNC_DT 2026-12-10 11:00:00. The robot reads the views with that SYNC_DT and fills up to three files. Pick a scenario.

OPERATION_TYPE decides the file order of a part
