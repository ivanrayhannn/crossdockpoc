Staging sync SQL sandbox

The tables hold the data of the full flow simulation (Nov 2026 – Jan 2027, dummy parts) plus the earlier Oct run of 202611. Pick a saved query or write your own and press Run (Ctrl + Enter). The parameters are at the top of each query in the WITH p AS (...) part: change the run ID or the dates there. The database runs only in your browser; Reset data restores it.

SQLite dialect. For SQL Server: || → +, SUBSTR → SUBSTRING, IFNULL → ISNULL, LENGTH → LEN, SUM(x = 'y') → SUM(CASE WHEN x = 'y' THEN 1 ELSE 0 END).
